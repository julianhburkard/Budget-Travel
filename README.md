# Trip Budget

Plan a trip's full cost before you go: set a total budget and travel dates, add fixed costs, and plan each day.

**Live app:** https://julianhburkard.github.io/Budget-Travel/

## Run it

```bash
npm install
npm run dev
```

`npm test` runs the budget-math tests; `npm run build` makes a production build in `dist/`.

## Destination estimate

Pick a destination city to see typical lodging per night and meals per day, based on U.S. government per diem rates:

- **Foreign cities:** U.S. State Department maximum per diem rates.
- **U.S. cities:** GSA per diem rates (continental U.S.; Alaska and Hawaii aren't included yet).
- Every country and state also has an "Other locations in …" rate for places not listed by name.

Per diem rates are set for business travelers, so the estimate uses a percentage of them (**75% by default**, adjustable per trip). Buttons apply the estimate to the trip's lodging and food & drinks budget.

The rates live in `public/data/per-diem.json`, generated by `npm run data` (`scripts/fetch-per-diem.mjs`). The **Refresh per diem rates** GitHub Action reruns it on the 3rd of each month and redeploys the site when rates change. GSA's API uses the public `DEMO_KEY` unless a `GSA_API_KEY` repository secret is set (free key from https://api.data.gov/signup).

## How costs are counted

- **Trip days** include both the start and end dates.
- **Flights, lodging and rental cars** are fixed costs. In "Spread fixed costs" mode, each is divided evenly across every trip day. In "On actual dates" mode, flights land on their date, lodging is split across its nights (check-in up to the day before check-out), and a rental car is split across its rental days. The trip total is the same either way.
- **Food & drinks**: a daily amount set in the summary; you can override it on any single day.
- **Unplanned expenses**: a % (default 10%) added on top of all planned spending.
- **Average cost / day** = planned trip cost (including unplanned) ÷ trip days. **Budget / day** = total budget ÷ trip days.

Trips are saved in the browser's localStorage. There's no account or server yet.

## Code layout

- `src/lib/budget.ts`: all budget math (`summarize`), with tests in `budget.test.ts`
- `src/lib/storage.ts`: trip list and localStorage saving
- `src/lib/perDiem.ts`: per diem lookup, seasonal rates, estimates and city search (tests in `perDiem.test.ts`)
- `src/components/DestinationEstimate.tsx`, `CityPicker.tsx`: the destination estimate section
- `src/components/SummaryHeader.tsx`: budget, dates, stats, flights, lodging, and rental cars
- `src/components/Ledger.tsx`: day-by-day cards and activities
